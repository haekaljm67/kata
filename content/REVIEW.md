# Native speaker review list

All lesson content was written without a native speaker. Every word is
marked `"nativeCheck": "needed"` in `words.json`. This list points out
the items I'm **least sure about**, so a reviewer can start there.

When an item is checked, fix anything that's wrong, delete it from this
list, and set the word's `nativeCheck` to `"done"` once the whole word
(sentence, translation and notes) has been reviewed.

## Japanese

| Word | Field | What to check |
| --- | --- | --- |
| ありがとう | `blank.tip` | Is "どうも usually comes right before words of thanks" fair? どうもすみません and casual どうも、こんにちは also exist. |
| すみません | `sound` | The description of the light first "u" (sounding like "smi-ma-sen"). Is this a helpful way to describe it? |
| いいえ | `meaning` | Is いいえ still a natural reply to thanks today, or does it sound dated next to いえいえ? |
| 友だち | `meaning` | The note that だち was originally a plural marker. True historically, but is it helpful at N5? |
| 大きい | `blank.tip` | "Two nouns can't sit side by side like this." Simplified on purpose, since noun + の + noun exists. Is the wording misleading? |
| 本 | `meaning` | The note that 本 in 日本 means "origin". Simplified; check that it isn't misleading. |
| おはよう | `example` | "おはよう、ゆきさん。" Is casual おはよう with さん natural, or should it be おはようございます? |
| All | `sound` | The notes avoid pitch accent on purpose. A reviewer might add simple pitch tips later. |
